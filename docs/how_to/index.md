# How to...

This section shows how to create new versions and maintain old ones. Each article covers one type of breaking change.

To follow this guide, choose a type of an entity that you'd like to alter (an endpoint, a schema, etc), find the respective article, and follow its instructions. Repeat for every breaking change you would like to do.

Versioning has more pitfalls than you'd expect, so **do not skip this guide**, or your code will quickly become unmaintainable. You can combine any of these scenarios, even within a single version change, though it's recommended to keep version changes atomic as described in the [methodology](../concepts/methodology.md) section.
